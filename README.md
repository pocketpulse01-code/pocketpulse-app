## Android app

Source: android/ (com.pocketpulse.app). App data stays on the device. Firebase sync, analytics, and install tracking are not implemented.

GitHub Actions builds a debug APK artifact. This app is not published on Google Play. Private install reports require a Play release and are available in Play Console.
